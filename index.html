Send it to the Flipper

  1. Tap Save payload. The file lands in your Downloads folder.
  2. Open the Flipper mobile app, connected over Bluetooth.
  3. Go to Options → File Manager → ext → apps_data → ez_sign and upload the file.
  4. On the Flipper: Apps → NFC → EZ Sign Writer, press OK, pick the file, hold it on the sign.

Everything is generated on this device. Nothing about your image leaves the page except the file you choose to save.
